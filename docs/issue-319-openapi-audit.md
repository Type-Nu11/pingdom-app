## 계약 판정

- password: POST /users/change-pw 존재. ChangePasswordRequest의 currentPassword/newPassword/confirmPassword와 기존 V2 현재 비밀번호 폼 재사용.
- deletion: DELETE /users/me 존재. 재인증·확인 정책 미확정이므로 호출 제외.
- export: GET /users/me/export 존재. docs/api/account.openapi.json / generated/account.ts / useDownloadUserDataExport 재사용.
- reviews: totalElements optional. 미제공을 0으로 만들지 않음.
- coupons: totalElements required. 기존 offers-coupons canonical snapshot/generated 타입·Query 재사용.
- check-ins: totalElements optional. 고유 place count가 아닌 체크인 수. 기존 place-exploration generated wire 타입 재사용.
- OAuth: link POST / unlink DELETE만 존재. GET 연결 상태 operation 없음. MyPageResponse에도 linked 필드 없음.
- 직접 이메일 수정 경로 없음.
- 계정 export snapshot과 live 문서의 필드 추가/삭제 차이는 arbitrary object를 수기 DTO로 확장하지 않는다. 기존 generated export 타입을 사용하며 실제 반환 JSON은 기존 writer가 직렬화한다.
