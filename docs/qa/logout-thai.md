# 로그아웃 진입 분기와 태국어 추가

## 로그아웃

온보딩 완료 기록 없이 토큰만 복원된 기존 계정은 로그인 중에는 지도로 진입하지만, 로그아웃하면 완료 기록 기준의 최초 실행 분기로 되돌아갔다.

- 인증 저장소와 앱 진입을 잇는 기존 공통 경계 `src/app/store/**`, `src/app/navigation/AuthNavigator.tsx`, `src/application/navigation/**` 및 V2 온보딩 진입 모델을 수정했다.
- 기기 로그인 이력 `@pingdom/has-authenticated:v1`을 인증 토큰과 별도로 저장한다. 토큰 복원·로그인·로그아웃·세션 만료에서 유지한다. 자격 증명이나 사용자 신상정보를 저장하는 값은 아니다.
- 로그인 이력이 있으면 온보딩 완료 기록이 없어도 로그인·회원가입 진입 화면을 연다. 앱을 다시 켜도 동일하다. 온보딩 완료·로그인 이력이 모두 없는 첫 설치는 기존 온보딩을 유지한다.
- 생년·국가·언어 등 누락된 가입 정보를 임의의 값으로 만들어 완료 기록을 생성하지 않는다. 기존 완료 기록은 보존한다.
- 저장소 장애가 로그인이나 토큰 삭제를 막지 않도록 한다. 저장 실패 시 현재 세션의 이력은 유지되지만 재시작 후 영속성은 보장할 수 없다.

## 태국어

- `th`를 9번째 지원 언어로 추가했다. 언어 선택·설정에서 `ภาษาไทย`로 표시하며 `th`, `th-TH`, `th_TH`, `Thai`, `ภาษาไทย`, `태국어`를 인식한다.
- 공통 카탈로그와 각 기능 소유의 카탈로그에 태국어 번역을 추가했다. 영어 카탈로그로 대체하는 방식이 아니다.
- 로그인·회원가입·온보딩·설정·지도·장소·길찾기·예약·쿠폰·결제·방문 인증·커뮤니티·음성 도우미의 기존 번역 키를 포함한다.
- 보간 변수, 태그, 개행, 양끝 공백과 복수형을 전체 카탈로그 테스트로 확인한다. 언어명·고유명사·단위는 의도된 원어 표기를 유지할 수 있다.
- `Intl.RelativeTimeFormat`이 없는 런타임의 상대시간도 태국어로 표시한다. 기존 통화·시간대 의미는 바꾸지 않는다.
- iOS 기기 언어 인식을 위해 `app.json`과 `ios/Naviapp/Info.plist`의 `CFBundleLocalizations`에 `th`를 추가했다. 설치된 이전 iOS 바이너리에 이 선언을 반영하려면 네이티브 재빌드가 필요하다.

## 검증 범위

- 기존 계정의 완료 기록 누락 → 로그아웃 → 인증 진입, 로그인 이력 저장 후 재시작, 첫 설치 온보딩 유지, 실제 AuthNavigator의 로그인·회원가입 버튼 및 로그인 폼 진입을 자동 테스트했다.
- 언어 정규화·언어 선택·온보딩 완료 복원·앱/테스트 번역 조립 및 전체 태국어 키 계약을 자동 테스트했다.
- 실제 로그인 서버 호출, Android/iOS 설치·표시·태국어 글리프/줄바꿈 검증은 하지 않았다. UI 번역을 태국어 음성 인식이나 서버 생성 콘텐츠의 번역 보장으로 간주하지 않는다.
- 구현 위치: V2 및 기존 공통 인증/앱 진입 경계. V1 dependency delta: **none**. `src/features/**` 수정과 신규 V1 의존성은 없다.

## 국적 및 관심사 화면 후속

- 사용자 제공 SVG 원본을 `src/assets/v2/flags/{ar,br,ca,es,gb,pt,sg}.svg`로 복사했다. 7개 파일의 SHA-256이 원본과 일치한다.
- 아르헨티나·브라질·캐나다·스페인·영국·포르투갈·싱가포르를 추가해 온보딩 국가 선택지를 13개로 늘렸다. 국기와 현지화된 나라명을 가로로 배치하며 선택·검색을 지원한다.
- 나라명은 태국어를 포함한 9개 지원 언어에 추가했다. 새 국가도 온보딩 완료 기록에 저장·복원할 수 있다. 영국 코드는 ISO 코드 `GB`다.
- 기존 온보딩 흐름이 선택 코드를 가입 컨텍스트의 `country`로 그대로 전달한다. 기존 가입 요청 타입은 `country?: string`이며 국가별 실제 서버 가입은 실행하지 않았다.
- 관심사 화면의 제목·목록을 진행 표시와 하단 버튼 사이에서 세로 중앙 정렬한다. 스크롤 컨테이너의 `flexGrow`를 사용하므로 내용이 화면보다 길면 스크롤을 유지한다.
- 온보딩 관련 15 suites / 145 tests와 전체 번역 카탈로그 96건이 통과했다. 연결 가능한 브라우저가 없어 로컬 시각 확인은 미실시이며, 실기기 표시 검증도 남아 있다.
- 모든 후속 작업을 포함한 최종 `npm run validate:pr`가 종료 코드 0으로 통과했다. V2 경계 76건, ownership 2건, TypeScript, 전체 Jest 215 suites / 2,607 tests 및 후속 회귀 검증이 통과했다. `git diff --check`도 통과했다.
