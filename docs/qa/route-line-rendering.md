# 경로선 렌더링 최종 변경

- Android/iOS 네이티브 공용 지도 경계와 V2 지도 어댑터를 수정했다. V1 dependency delta: none.
- 최종 경로선은 브랜드색 `#FF1956` 단색, 줌에 따라 8~9dp/pt다. 외곽선·그림자·반복 방향 화살표가 없다.
- 끝과 연결부를 둥글게 표시하고, 어댑터에서 꺾임 주변 최대 6m만 이차 베지어 곡선으로 처리한다. 원래 선에서 이탈하는 범위는 최대 3m로 제한한다. 짧은 구간은 인접 구간의 1/4까지만 다듬는다.
- 서버 좌표는 변경하지 않는다. 시작/끝 좌표, 거리·소요 시간·도착 판정은 원본 데이터를 유지한다. GPS 갱신만으로 표시 좌표를 다시 만들지 않는다.
- Android SM-N981N: 디버그 빌드/설치 후 임시 경로 fixture를 실제 네이티브 지도에 표시해 곡선과 굵기를 확인했다. 실제 서버 경로/주행 검증과는 구분한다.
- 캡처: `/private/tmp/route-curves-after.png`, `/private/tmp/route-curves-raw.png`.
- Swift 문법 검사 통과. iOS 전체 빌드와 화면 확인은 로컬 iOS 26.2 플랫폼 미설치로 미완료다.
- 임시 App.tsx 프리뷰는 원본으로 복구했다.
