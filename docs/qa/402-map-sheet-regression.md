# 지도 공통 버튼 및 장소 사진 경계 회귀 수정

2026-10-19, Android SM-F966N / API 36 실제 표시 화면에서 확인. 기존 다운로드형 장소명 번역 변경은 보존했다.

## 원인과 수정

- AI 버튼이 지도 홈에서만 렌더링되고, 검증하기 버튼은 커뮤니티·장소 미리보기 등에서 제외되고 있었다. 검색/길찾기 전용 오버레이가 없는 지도 시트에서는 탭/장소 선택에 관계없이 두 버튼을 제공한다. 지도를 덮는 전체 확장 상태에서는 기존 동작대로 숨기고 접근성과 터치도 제외한다.
- 둥근 시트 배경과 실제 콘텐츠가 별도의 형제 뷰였고, 콘텐츠는 전체 화면 높이와 `overflow: visible`을 사용했다. 배경의 아래쪽 모서리를 넘어 사진이 표시됐다.
- 실제 콘텐츠에 시트 배경과 동일한 animated 좌우/하단 경계 및 모서리 반경을 가진 `SheetContentViewport`를 적용했다. 사진 등 자식 콘텐츠를 그 경계 안에서 자른다. 시트 그림자, 하단 내비게이션, 사진 모달은 클리핑 바깥에서 기존 역할을 유지한다.
- 새 경계가 resting inset을 담당하므로 내부의 중복 가로 inset을 제거했다. 기존 제목 x 좌표를 유지하며 전체 확장 때는 inset과 모서리 반경이 0으로 전환된다.

## Android 실기기 확인

- 즐겨찾기 선택 상태: AI 및 검증하기 버튼 모두 표시.
- 커뮤니티 선택 상태: 두 버튼 모두 표시.
- 예약 선택 상태: 두 버튼 모두 표시.
- 실제 `대구예술발전소` 장소 미리보기: 두 버튼 표시. 사진은 시트의 아래쪽 곡선을 따라 클리핑되고 하단 바깥으로 넘치지 않음.
- 같은 장소를 전체 확장: 상세 사진·정보·상품 콘텐츠가 정상 표시. 지도 공통 버튼은 화면/접근성에서 숨김.
- 하단 탭을 가리는 개발 LogBox 배너를 닫은 상태에서 탭 선택 상태와 버튼 접근성 노드를 함께 확인했다. 하단 탭을 실제로 전환하지 않은 화면을 검증 증거로 사용하지 않았다.
- iOS 실기기 시각 검증은 하지 않았다.
