## 구현

- 44dp 원형 유리 버튼과 간격 12dp, Figma의 24×24 화살표 SVG 도형을 사용하고 색상은 테마를 따른다. 임시 URL 대신 routes/assets/map_directions.svg에 도형을 저장했고 버튼에 크기 변형 없이 사용한다.
- 버튼은 음성 AI feature flag와 분리돼 길찾기 화면을 연다. 입력 화면이 열려 있는 동안 지도 호출어 청취를 일시 중지한다.
- CarRoutePreview의 null 출발/도착은 빈 칸으로 취급한다. 현재 위치 추적은 명시적인 isCurrentLocation 선택과 분리했다. 메인 진입은 GPS가 있어도 두 칸을 비워 두고, GPS 갱신·출발/도착 교환 시에도 자동 입력하지 않는다.
- 두 지점의 좌표가 모두 선택되기 전에는 경로 API를 요청하지 않는다. 검색·저장 장소·지도 선택과 명시적인 현재 위치 선택을 기존 편집 화면으로 제공한다.
- 장소 상세에서 특정 출발/도착을 전달하는 기존 동작은 유지한다. 빈 입력과 별개로 지도 카메라는 사용 가능한 현재 위치로 시작할 수 있다.
