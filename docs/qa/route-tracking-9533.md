## 앱 디자인 안내창과 정밀 위치 재확인 (2026-10-12 후속 수정)

- 경로 시작 실패 및 외부 지도 실행 실패의 네이티브 `Alert`를 앱의 GlassSurface, 테마, Typography, 둥근 버튼을 사용하는 안내창으로 교체했다. 뒤로가기/닫기/배경 터치로 닫고, 안내 중에는 뒤쪽 화면의 터치와 접근성 탐색을 차단한다.
- 기존 지도 위치는 Balanced 정확도, 10m 이동 간격으로 수집되지만 시작 검사는 15초 이내 위치를 요구했다. 정지 중 오래된 위치 또는 낮은 정확도 때문에 시작이 막힐 수 있어, 이 경우 High 정확도 위치를 최대 12초 기다린 뒤 다시 검증한다. 유효하면 추가 탭 없이 시작한다.

- 위치 확인을 닫거나 화면을 나간 뒤 도착한 응답은 따라가기를 시작하지 않는다. 따라가기 중 전경에서는 정밀 위치를 수집하며, 종료·도착·배경 전환 시 구독을 해제한다.

## 선택한 출발지 가정으로 시작 (2026-10-12 최종 후속 수정)

- 사용자의 명시적인 요청에 따라 출발지와 실제 GPS가 다르다는 이유로 시작을 막지 않는다. 선택한 출발지에 있다고 가정하여 기존 경로와 조회 당시 소요 시간을 바로 표시한다.
- 직접 선택한 출발지에서 GPS가 멀거나 오래됐거나 권한이 없어도 `출발지 기준 미리보기`로 진입한다. 이 상태에서는 지도 중심과 거리 기준을 선택한 출발지에 고정하고, GPS 구독/자동 도착 판정을 하지 않는다. 지도 이동 후 복구 버튼은 출발지로 돌아간다. 가상의 주행 진행이나 회전 안내는 생성하지 않는다.
- 실제 GPS가 출발지 근처에서 유효하면 기존 실제 위치 따라가기를 사용한다. 현재 위치 출발의 정밀 위치 재확인도 유지한다.
- `다이소 → 선택 당시 내 위치`에서 실제 GPS가 목적지에 있더라도 미리보기가 즉시 도착 처리되지 않는 것을 검증했다. 위치 권한 없이 고정 출발지 시작, 지도 이동 후 출발지 복구, 종료 후 목적지 유지, 출발지 근처의 실제 따라가기/도착도 검증했다.
- `npm run test:v2-routes`: 7개 스위트, 117개 통과. `npm run typecheck`, `npm run check:v2`(76개), `git diff --check` 통과.
- 이번 변경의 실기기 화면 재확인은 수행하지 않았다. 연결된 기기가 다른 앱을 사용 중이어서 전환하지 않았다. 앞선 안내창 캡처는 이번 미리보기 동작의 증거가 아니다.
- V1 dependency delta: `none`. 커밋·푸시 없음.
