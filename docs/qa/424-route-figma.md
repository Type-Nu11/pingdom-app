## 디자인과 계약의 결정

- **페이지 표시 제외:** [현재 `/routes` 계약](../api/routes.openapi.json)은 NAVER `traoptimal`
  자동차 경로 **1개**를 반환하고 복수 경로를 지원하지 않는다. 실제 탐색 대상이 없어 고정 3개 점과
  동작 없는 carousel을 구현하지 않았다. 대안 경로 계약이 생기면 탐색 동작과 함께 추가한다.
- **자동차 CTA:** 사용자 추가 요청으로 성공 화면의 `시작`은 앱 내부 경로 따라가기로 변경했다.
  현재 위치를 출발지로 조회한 경로는 재사용하고, 임의 출발지로 미리 본 경로는 시작 시 실제 GPS에서
  고정 목적지까지 새로 조회한다. 안내 중 목적지·경로는 GPS 변화와 독립적으로 유지한다.
  미지원 이동수단 및 실패 상태에서는 기존 외부 지도 복구를 유지한다.
  Figma SummaryCard 주석의 `기사님께 보여주기`는 제외한다.
- **도착 판정:** 15초 이내 위치만 추적하며 직선 거리와 GPS 정확도 합이 30m 이하일 때 도착을
  확정한다. 좌표·정확도·시각이 잘못됐거나 권한 거부·백그라운드일 때는 도착을 판정하지 않는다.
  도착은 확정 후 유지한다. 표시 거리는 도로상 잔여 거리가 아닌 **목적지까지 직선 거리**다.
- **이번 안내 범위:** 화면이 열려 있는 동안 현재 위치 따라가기와 도착 확인이다. 회전·음성 안내,
  경로 이탈 감지·재탐색, 백그라운드 안내는 이번에 추가하지 않는다. 안내 종료 시 미리보기로 돌아간다.
- **추가 정보 제외:** 통행료·실시간 교통 반영 여부·미래 출발 시각·막차 시각은 현재 앱 계약에 근거
  필드가 없어 표시하지 않는다. 공급자 예상 경로라는 실제 안내만 유지한다.
- **대중교통·도보·자전거 상세 제외:** 현재 계약이 미지원이라고 명시한다. 요금·환승·노선·정류장·도착
  예정·대안 경로를 추정하지 않고 기존 외부 지도 연결을 유지한다. 이 UI 이슈에서 기능을 확장하지 않는다.
