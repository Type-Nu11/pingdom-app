# 하단 내비게이션 수정

- 누르는 동안 생기던 회색 강조를 제거했다. 실제 선택 상태와 드래그 탭 전환은 유지한다.
- 튜토리얼은 사용자 요청 범위가 아니므로 유지한다.
- 선택 배경은 고정 78px 대신 탭 칸의 100% 너비(최대 78px)를 사용해 지도/예약 양끝 잘림을 해결했다. 음수 gap은 사용하지 않았다.
- 예약 선택 아이콘 내부 체크는 밝은 전경색 `#F6F6F7`을 사용한다.
- Android SM-N981N: 즐겨찾기 DOWN 유지 시 회색 강조가 없는 것, 지도와 예약 선택 배경, 예약 체크 색상 확인.
- 캡처: `/private/tmp/nav-touch-held.png`, `/private/tmp/nav-width-reservation.png`.
- 내비게이션 7개 테스트, 타입 검사, V2 경계 76개 통과. iOS 실기기 확인은 미완료.
- V1 dependency delta: none.
