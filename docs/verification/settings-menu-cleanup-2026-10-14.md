# 설정 메뉴 정리 (2026-10-14)

구현 위치: V2. V1 dependency delta: none.

사용자 지정 메뉴인 내 발자국 지도·관심 장소 관리·내 기록 관리·공지사항·이용약관·
개인정보 처리방침을 설정 루트에서 제거했습니다. 기능이 중복되거나 미지원인 메뉴도
계정 관리·위치·데이터·알림 하위 화면에서 제거했습니다.

- 설정 루트: 계정 관리, 알림 설정, 화면 모드, 언어, 위치 정보 설정, 데이터 관리, 버전 정보.
  맨 아래에는 로그아웃과 회원 탈퇴 버튼을 둡니다.
- 계정 관리: 역할이 허용하는 프로필 편집, 실제 로그인 정보, 서버 기반 리뷰/체크인 수,
  쿠폰함. 로그아웃과 회원 탈퇴는 계정 관리에 두지 않습니다.
- 위치: OS 위치 권한 확인/요청/설정 진입, GPS 현장 인증 가능 상태 조회.
- 데이터: 기존 사용자 확인 후 데이터 다운로드 진입점.
- 알림: OS 알림 권한 조회/설정 진입, 실제 서버 기반 핫플레이스·좋아요 알림 변경.

비밀번호 변경은 프로필 편집과 같은 화면에 연결돼 메뉴에서 제거했습니다.
이메일 수정, 계정 연결, 미지원 검증 수, 위치 공개 범위·닉네임 표시·기록 삭제,
미지원 알림 스위치·방해 금지 편집도 제거했습니다. 중복된 프로필·쿠폰은 계정 관리에 모았고 데이터 내보내기는 데이터 관리에서만 제공합니다.
기존 내부 상세 식별자와 호환 라우트는 유지합니다. UI 메뉴 제거가 서버 데이터 삭제는 아닙니다.

버전 표시의 하드코딩 3.0.0을 제거하고 app.config.js와 같은 appMetadata.json 값을 사용합니다.

실제 Android SM-N981N에서 root → 계정 관리 → 알림 → 위치 → 데이터 화면을 확인했습니다.
알림 스위치·로그아웃·데이터 다운로드 버튼을 실행하지 않았습니다.
캡처: /private/tmp/settings-cleanup-{root,account,notifications,location,data}.png.

기존 설정·알림 테스트를 새 메뉴 구성에 맞춰 수정했습니다. 타입 검사, check:v2 76 tests,
diff --check 통과. 해당 QA 시점에는 커밋·푸시를 하지 않았습니다.

기존 운영/독립 내비게이터 테스트도 제거된 루트 메뉴 대신 계정 관리의 실제 진입점과
설정 루트의 남은 메뉴를 검증하도록 수정했습니다. 전체 Jest 205 suites/2479 tests 통과.

사용자 정정에 따라 로그아웃·회원 탈퇴는 설정 하단으로 복원했습니다.
회원 탈퇴는 기존 안내 진입점을 유지하며 실제 계정 삭제를 실행하지 않습니다.
복원 후 실기기 캡처: /private/tmp/settings-footer-restored.png.
