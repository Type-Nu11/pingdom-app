# Android 개발용 서명 키

모든 개발 기기와 작업 폴더는 동일한 개발용 키를 사용합니다.

- 기본 경로: `~/.android/pingdom-debug.keystore`
- 별칭: `androiddebugkey`
- 개발용 저장소/키 비밀번호: `android`
- SHA-256: `84:D9:17:90:B4:4B:C9:57:B9:EE:D6:AB:30:D2:AA:79:F9:F5:D2:0B:18:89:C5:78:A6:52:12:3C:55:52:A6:B8`

`android/app/debug.keystore`는 빌드에 사용하지 않습니다. 작업 폴더별로 키를 생성하거나 교체하지 마세요.
다른 컴퓨터나 CI에서는 동일한 키 파일을 전달받아 기본 경로에 설치하거나 `PINGDOM_DEBUG_KEYSTORE`로 경로를 지정합니다.
키 파일은 Git에 올리지 않습니다. 키가 없거나 인증서 지문이 다르면 서명 검증 단계에서 빌드가 실패합니다.

검증 명령:

```sh
cd android
./gradlew :app:validateSigningDebug
```

이 설정 변경은 각 브랜치에 반영되어야 합니다. 변경 전 브랜치는 여전히 작업 폴더의 키를 사용할 수 있습니다.

다른 키로 이미 설치된 앱은 덮어쓸 수 없습니다. 최초 전환 시 해당 기기의 앱 삭제와 재설치가 필요할 수 있고,
앱 삭제는 로컬 데이터를 지우므로 반드시 사용자 승인 후 진행합니다.

이 키는 개발용입니다. 현재 저장소의 release 구성도 debug 서명을 참조하므로 같은 키를 사용하며,
실제 배포용 서명은 별도로 구성해야 합니다.
