# 접근성·국제화 공통 컴포넌트 체크리스트

신규 화면과 공통 컴포넌트의 PR 리뷰 및 QA에서 아래 항목을 모두 확인한다. 대상 지원 언어는 `en`, `ko`, `ja`, `zh`, `vi`, `th`이며, RTL은 향후 언어 추가가 가능한 구조를 유지한다.

## 공통 기준

- 버튼: `accessibilityRole="button"`, 동작을 설명하는 라벨, 필요할 때만 결과 중심 힌트를 제공한다. 비활성/로딩은 `accessibilityState.disabled/busy`로 전달한다.
- 입력: 화면에 보이는 라벨과 접근성 라벨을 일치시키고, 필수 여부와 오류를 텍스트로 표시한다. 오류는 `invalid` 상태와 `polite` 라이브 리전으로도 전달한다.
- 모달: 제목, 닫기 동작, Android 뒤로 가기를 지원하고 `accessibilityViewIsModal`로 배경 탐색을 차단한다. 본문은 큰 글꼴에서도 스크롤 가능해야 한다.
- 상태 배지: 색상만 사용하지 않는다. 상태 텍스트와 기호를 함께 표시하고 보조 기술에는 완전한 상태 문구를 제공한다.
- 로딩·오류·검증: 시각적 표시와 함께 상태가 바뀌는 시점에 한 번만 스크린리더로 알린다. 반복 렌더링으로 같은 메시지를 재안내하지 않는다.
- 터치 영역: 모든 상호작용 요소는 최소 `44×44pt`이며 핵심 CTA는 최소 높이 `48pt`를 사용한다.
- 동적 글꼴: 핵심 정보와 CTA에는 `allowFontScaling={false}`를 사용하지 않는다. 고정 높이와 한 줄 제한을 피하고 세로 확장 또는 스크롤을 허용한다.
- 포커스 순서: 제목 → 설명/상태 → 주요 동작 → 보조 동작 순으로 시각적 순서와 접근성 순서를 일치시킨다.

## 번역문·줄바꿈·RTL

- 핵심 CTA는 `numberOfLines`와 말줄임표를 사용하지 않고 가운데 정렬하며 여러 줄로 확장한다.
- 장소명처럼 반복 목록에서만 제한이 필요한 정보는 최대 2줄까지 허용하고, 전체 문자열을 접근성 라벨이나 상세 화면에서 제공한다.
- 주소·검증·오류처럼 의사결정에 필요한 문구는 자르지 않는다. 공간이 부족하면 카드 전체가 세로로 늘어나거나 스크롤된다.
- 가로 CTA 묶음은 `flexWrap: 'wrap'`과 합리적인 `minWidth`를 사용한다. 번역이 길면 버튼이 다음 줄로 이동한다.
- 좌우 의미가 있는 아이콘은 `I18nManager.isRTL`에 따라 반전한다. 레이아웃은 가능한 `start/end` 개념을 사용하고 문자열에 화살표·공백을 결합하지 않는다.
- 아랍어 같은 RTL 언어 추가 시 `I18nManager.forceRTL` 스모크 테스트를 수행하며, 숫자·통화·주소가 문장 안에서 올바른 순서인지 확인한다.

## 로컬라이징

- 날짜·시간은 `formatLocalDateTime`, 통화는 `formatCurrency`, 거리는 `formatDistance`를 사용한다.
- 서버에서 표시용 문자열을 받지 말고 원시 값(ISO 날짜, 통화 코드와 금액, 미터)을 받아 기기 언어에서 포맷한다.
- 시간대는 기기 시간대를 기본으로 하며, 장소 현지 시간이 필요한 기능은 명시적인 IANA 시간대를 함께 전달한다.
- 통화 기호만으로 통화를 추정하지 않는다. API의 ISO 4217 통화 코드를 사용한다.

## 화면 적용 현황

| 화면 | 적용 기준 |
| --- | --- |
| 지도 카드/하단 패널 | 필터 선택 상태, 검색·프로필·카드·CTA 역할, 44pt 터치 영역, 상태 텍스트+색, 거리 포맷, 긴 CTA 줄바꿈 |
| 장소 상세 | 번역 제목·CTA, 상태 배지, 날짜·시간·통화·거리 포맷, 스크롤과 다중 줄 CTA |
| 체크인 | 번역 설명·CTA, 경고/완료 상태 배지, 완료 라이브 안내, 다중 줄 CTA |
| 쿠폰 | 번역 빈 상태·CTA, 중립 상태 배지, 스크롤과 다중 줄 CTA |

## 지원 언어 QA 매트릭스

각 언어에서 320pt 너비와 시스템 글꼴 200%를 조합해 아래를 확인한다.

- 장소 상세의 체크인·쿠폰·뒤로가기 CTA 전체 문구가 보인다.
- 체크인의 핵심 CTA 전체 문구가 보이고 터치 영역이 유지된다.
- 쿠폰의 탐색 CTA 전체 문구가 보이고 화면 세로 스크롤로 도달할 수 있다.
- 지도 추천 카드와 장소 미리보기의 쿠폰·바로가기 CTA가 줄바꿈되거나 다음 줄로 이동하며 잘리지 않는다.
- VoiceOver/TalkBack에서 제목, 상태, 설명, CTA 순으로 읽히고 선택/완료 상태가 문구로 전달된다.

검증 결과는 PR에 `언어 / 화면 / 200% 글꼴 / 스크린리더` 네 항목으로 기록한다.
