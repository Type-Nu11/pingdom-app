# Asset structure

- `v2/`: 현재 앱 코드 또는 Expo 설정에서 참조하는 자산
  - `flags/`: 국가 선택 국기
  - `icons/`: 공통·기능별 아이콘
  - `icons/place/`: 지도, 장소, 바텀 시트 전용 아이콘
  - `images/`: 현재 화면에서 사용하는 래스터 이미지
- `v1/`: 현재 코드와 설정에서 참조하지 않는 레거시 자산 보관소

새 화면에서는 `v2/` 자산만 참조합니다. `v1/` 자산을 다시 사용할 때는 먼저 `v2/`의 알맞은 하위 폴더로 이동한 뒤 import합니다.
